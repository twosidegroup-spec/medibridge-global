# MediBridge Global

Medical tourism platform — treatment abroad, with the price known before the patient flies.

**Features**
- Live treatment search with specialty filters and price sorting
- Price estimator across six destinations (Bangkok, New Delhi & Chennai, Istanbul, Kuala Lumpur, Dubai, Singapore) and four currencies (USD, EUR, GBP, BDT)
- Hospital profiles with quality sub-scores, doctor profiles, fixed-price packages
- Enquiry flow with inline validation and WhatsApp / email handover
- Seamless destination and patient-story marquees with real flag graphics
- Fully responsive — small phones to ultra-wide monitors; reduced-motion support

**Design & build**
IBM Plex Serif / Sans / Mono type system, flat forest-emerald institutional palette, plain-language UX a first-time patient can follow unaided. Single self-contained HTML file — open `index.html` in any browser.

Built by **TwoSide Group** (TS Technologies) — custom code only, no templates, no page builders.
